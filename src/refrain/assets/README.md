# Bundled Visual Assets

This directory contains visual resources distributed with Refrain.

## Backgrounds and Decorations

The PNG images under `backgrounds/` and `decorations/` were generated specifically for Refrain using OpenAI image-generation tools, with human creative direction, selection, and review.

These assets are distributed under the repository's MIT License to the extent that applicable intellectual-property rights exist.

The artwork may be refined or replaced as Refrain evolves. Stable resource identifiers are documented separately in the content and configuration specification.
